# Elka AudioLink

Windows x64 OBS monitor-return sender and companion receiver with local VBAN or
direct VoiceMeeter callback output. Pick one input strip OR A bus. Bus return gain
is independent of existing audio and applies live without reconnecting.
Build with Visual Studio 2026 / v145. This repository is independent of VBAN Stream.

Keep user documentation focused on setup and operation. Network and audio work must
remain outside OBS capture callbacks. Do not claim remote VoiceMeeter reception
from a successful local UDP send.
